# Computational Experiments

A collection of computational experiments and exploratory studies spanning machine learning, optimization, statistical modelling, and data analytics originating from my graduate studies.

The repository explores different computational approaches to prediction, probabilistic inference, optimization, and data-driven analysis through practical implementations and experimental evaluation.

## Projects

| Project | Description |
|---|---|
| [Bayesian Network Recommendation](Bayesian-Network-Recommendation/) | A probabilistic recommendation model using Bayesian networks to estimate customer purchase likelihood based on purchase history, product ratings, and discounts. |
| [Genetic Algorithm for TSP](Genetic-Algorithm-for-TSP/) | An evolutionary optimization approach to the Travelling Salesman Problem, exploring crossover, mutation, population evolution, and parameter tuning. |
| [Decision Tree Classification](Decision-Tree-Classification/) | A decision tree model for vehicle evaluation, examining feature selection, classification performance, and the effects of data modifications. |
