# Case Studies

A collection of applied studies exploring machine learning, statistical modelling, and data analytics across practical problems.

These studies examine different approaches to predictive modelling, statistical inference, optimization, and data-driven decision-making.

## Machine Learning

| Study | Description |
|---|---|
| [Vehicle Price Regression and Text Mining](machine_learning/Vehicle_Price_Regression_and_Text_Mining.ipynb) | Vehicle price estimation using web scraping, exploratory data analysis, and regression modelling, with comparisons across regional markets. |
| [Customer Retention Prediction and Hypothesis Testing](machine_learning/Customer_Retention_Prediction_and_Hypothesis_Testing.ipynb) | Customer return-purchase prediction using logistic regression and random forests, alongside product analytics and statistical hypothesis testing. |
| [Bayside Real Estate K-Means Clustering](machine_learning/NYC_Real_Estate/Bayside_Real_Estate_KMeans_Clustering.ipynb) | Residential real estate analysis using PostgreSQL, K-Means clustering, statistical hypothesis testing, and data visualization. |
