# Case Studies

A collection of applied case studies exploring machine learning, statistical modelling, and computational methods across a variety of real-world datasets and problems.

## Machine Learning

| Study | Description |
|---|---|
| [Banknote Authentication](machine_learning/Banknote_Authentication.ipynb) | Banknote authenticity classification using K-nearest neighbors, logistic regression, exploratory feature analysis, and feature selection. |
| [Bayside Real Estate K-Means Clustering](machine_learning/Bayside_Real_Estate_KMeans_Clustering.ipynb) | Residential real estate analysis using PostgreSQL, K-Means clustering, statistical hypothesis testing, and data visualization. |
| [Cardiotocography Classification](machine_learning/Cardiotocography_Classification.ipynb) | Classification of cardiotocography measurements using Naive Bayes, decision trees, and random forests, with model comparisons and hyperparameter exploration. |
| [Customer Retention Prediction and Hypothesis Testing](machine_learning/Customer_Retention_Prediction_and_Hypothesis_Testing.ipynb) | Customer return-purchase prediction using logistic regression and random forests, alongside product analytics and statistical hypothesis testing. |
| [Vehicle Price Regression and Text Mining](machine_learning/Vehicle_Price_Regression_and_Text_Mining.ipynb) | Vehicle price estimation using web scraping, exploratory data analysis, and regression modelling, with comparisons across regional markets. |
| [Wheat Seed Classification and Clustering](machine_learning/Wheat_Seed_Classification_and_Clustering.ipynb) | Wheat seed classification with support vector machines and logistic regression, alongside K-Means clustering and centroid-based classification. |

## Statistical Modelling
